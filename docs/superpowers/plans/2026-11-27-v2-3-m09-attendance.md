# FactoryHR V2.3 M09｜考勤打卡与月结 — 详细实施计划
> **状态：** Proposed — 待用户确认；批准前不得执行。
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 或 superpowers:executing-plans；步骤用 `- [ ]` 跟踪。
**Goal:** 把十个考勤入口收敛为 `/attendance` 唯一工作区；九个旧子页折入同一个 profile-aware Tab/动作，复用已有考勤后端，并把考勤面板从 `TimePayrollPage` 迁出，不重写计算/月结内核。
**Architecture:** Time 独占 attendance day、rule、shift、schedule、correction、device、closure；本人和管理视角都由服务端 `TimeActor` 解析范围。工作区一个页面承载角色化 Tab（我的打卡/明细/日历/异常/补卡管理/规则/班次/排班/月结/设备），每个 Tab 只调用已有真实 API；安全设备仅在真实设备行存在时显示。
**Tech Stack:** Laravel 13 / PHP 8.3 / Vue 3.5 / TypeScript / Element Plus / PHPUnit / Vitest / Playwright / OpenAPI 3.1。
## Global Constraints
- `/attendance/{punches,calendar,rules,shifts,schedules,corrections,exceptions,closing,devices}` 九个旧入口删除，不保留重定向；`/attendance` KEEP。
- 原始打卡只追加、不编辑/删除；补卡经 Workflow Case，批准后由 `AttendanceCorrectionService::applyEffect()` 重算。
- 月结锁定后普通重算必须 409；重开必须 `time.attendance.reopen` + 原因 + 审计；本人 scope 固定为 session employment，管理员受 org/managed/COMPANY 范围约束，不得信任前端传 employee id。
- 复用现有后端 `AttendanceController`、`AttendanceOpsController`、`AttendanceClosingController`、`AttendanceCalculator`；仅补缺失读/导出端点时标新增。

1. 九个旧页仍由 `frontend/src/router/registry.ts`、`frontend/src/modules/timepay/pages/index.ts` 注册，全部经 `legacyBridge.ts` 渲染 `TimePayrollPage`/`AttendancePanel.vue`。

8. `AttendanceOpsService::devices()` 只读 `attendance_devices`，无写方法；没有真实设备行时旧入口仍显示，违背“有真实对接才显示”。

## 1. 目标契约
### 1.1 页面结构
`/attendance?tab=`：顶部月份/范围筛选 + 角色化 Tab：`my|punches|calendar|exceptions|corrections|rules|shifts|schedules|closing|devices`。可见性：本人/`time.attendance.read` 见 my；管理范围见 punches/calendar/exceptions/corrections；`rule.read/manage` 见 rules；`shift.read/manage` 见 shifts；`shift.schedule.read/manage` 见 schedules；`attendance.manage` 见 closing；`device.read` 且设备列表非空见 devices。Tab 由 capability 集合决定，不渲染无权 Tab；query 保留 `tab/month/employee/org_unit`。月结/规则/班次/排班/设备的写按钮各自 `ActionGate`。
### 1.2 DTO/API
| 能力 | API | 状态 | capability |
|---|---|---|---|
| 本人月份 | `GET /v1/time/attendance?month=` | 现有 | `time.attendance.read` |
| 指定员工月份 | `GET /v1/time/attendance/{employment_id}?from=&to=` | 现有 | `time.attendance.read` |
| 补卡申请 | `POST /v1/time/attendance/corrections` | 现有 | `time.attendance.correct.request` |
| 规则版本读/发 | `GET/POST /v1/time/attendance/rules` | 现有 | `time.attendance.rule.read/manage` |
| 班次读/建/改/停 | `GET /v1/time/shifts`、`POST/PATCH /v1/time/shifts` | 现有读 / **新增**写 | `time.shift.read`/**新增** `time.shift.manage` |
| 排班读/写 | `GET/POST /v1/time/shift-schedules` | 现有 | `time.shift.schedule.read/manage` |
| 关账/重开/重算/列表 | `GET/POST /v1/time/attendance/closings`、`.../{id}/reopen`、`/recalculate` | 现有 | `time.attendance.read/manage/reopen` |
| 设备 | `GET /v1/time/attendance/devices` | 现有 | `time.attendance.device.read` |
| 明细分页/导出 | `GET /v1/time/attendance/records?employment_id=&from=&to=&page=&page_size=` / `.../export` | **新增** | `time.attendance.read`/`export` |
| 原始打卡明细 | `GET /v1/time/punches?employment_id=&from=&to=&page=` | **新增** | `time.punch.read`（新增能力） |
`AttendanceRecord` `{employment_id,employee_no,employee_name,business_date,first_in,last_out,source,status,late_minutes,early_leave_minutes,absence_minutes,exception_label}`；`PunchRecord` `{id,employment_id,punched_at_utc,source,device_id}`；设备 DTO 现有 `{id,code,name,adapter,health,last_seen_at,active}`；新增导出仅字段白名单，金额不适用。新增 `records/punches` 端点先把当前 `/time/attendance/{id}` 的月份投影改造成可过滤分页，再由同一服务计算导出，避免第二套口径。
### 1.3 状态机
```text
AttendanceDay: OPEN --import/calculate--> PRESENT|LATE|EARLY|ABSENT|LEAVE|INCOMPLETE
Correction: DRAFT? --request--> SUBMITTED --approve--> APPLIED (recalculate once)
Period: OPEN --close--> CLOSED --reopen(reason)--> REOPENED --recalculate--> OPEN/CLOSED
Schedule: none --schedule(date,shift)--> SCHEDULED; conflict/closed period -> 409
Rule: version N --publish--> N+1; prior immutable
Shift: ACTIVE --disable--> DISABLED; used shift retains history
```
原始 punch 不可变；补卡/重算/关账均幂等；`CORRECTION_ALREADY_PENDING`、`SCHEDULE_CONFLICT`、`PERIOD_CLOSED` 保持稳定 reason。
### 1.4 权限
| 动作 | capability | 范围 |
|---|---|---|
| 本人/管理考勤读 | `time.attendance.read` | SELF/MANAGED/ORG_UNIT/ORG_SUBTREE/COMPANY |
| 补卡请求 | `time.attendance.correct.request` | SELF/MANAGED/ORG_UNIT/ORG_SUBTREE/COMPANY |
| 月结/重算/重开 | `time.attendance.manage/reopen` | ORG_UNIT/ORG_SUBTREE/COMPANY |
| 规则读/写 | `time.attendance.rule.read/manage` | ORG_UNIT/ORG_SUBTREE/COMPANY |
| 班次读/写 | `time.shift.read` / **新增** `time.shift.manage` | 读 SELF..COMPANY / 写 COMPANY |
| 排班读/写 | `time.shift.schedule.read/manage` | 同 Time actor |
| 设备读 | `time.attendance.device.read` | COMPANY |
| 明细导出 | **新增** `time.attendance.export` | 读取范围 + 字段白名单 |
