# FactoryHR V2.3 M19｜用户角色与细粒度权限 — 详细实施计划
> **状态：Proposed — 待用户确认。** 本计划不得在规格批准前执行。**For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
**Goal:** 保留 `/system/users`、`/system/roles`，新建 `/system/pages` 承接菜单与权限目录；将 `/system/menus`、`/system/permissions`、`/system/data-scopes`、`/system/field-policies` 折叠进页面目录或角色四个授权 Tab，并删除四个旧路由。
**Architecture:** `IAM` 独占用户、角色、页面注册/菜单覆盖、动作能力、数据锚点与字段档位。角色授权通过单个事务端点 `PUT /v1/roles/{id}/authorization` 一次提交页面、动作、锚点和字段档位；内置角色由代码拥有，只能复制，不能改名/删除/改授权，复制保留动作能力但页面授权按现有语义留空。`/system/pages` 只读页面目录 + 菜单显示覆盖；不生成第二套能力事实。
**Tech Stack:** Laravel 13 / PHP 8.3 / MySQL 8.4 / Vue 3.5 / TypeScript / Element Plus / PHPUnit / Vitest / Playwright / OpenAPI 3.1。
## Global Constraints
- 规范优先级：用户裁决 > 本计划 > V2.3 M19 模块规格 > V2.1 设计 > 历史文档；四个 `FOLD` IAM 路由不做重定向，registry、barrel、catalog、Vue、动作清单与旧测试同时删除。
- 页面授权不自动授予动作，隐藏按钮不代替服务端授权，字段裁剪与数据范围必须由后端执行；单公司单实例，不增加 tenant/legal-entity/SSO 选择器，不向业务管理员显示内部 ADR/能力码/代码路径。
- 所有写命令使用 `CommandRunner`/`IdempotencyRunner` + `Idempotency-Key` + `AuditRecorder`；角色授权保存必须原子；未执行测试、E2E、迁移演练写 `NOT RUN`。

## 2. 目标契约
```text
/system/users
├── 列表：账号、员工绑定、状态、分配角色 Drawer
└── 用户详情/角色预览：只读权限预览 + 角色 diff
/system/pages
├── 页面目录：页面代码、中文名、路由、所需能力（只读）
├── 菜单覆盖：可见开关、显示名、排序（iam.menu.manage）
└── 动作目录：页面 → 动作 → capability 只读矩阵
/system/roles
├── 角色列表：中文名、内置标记、成员数、动作数；新建/复制/删除
└── 授权工作台：页面权限 | 按钮动作 | 数据范围 | 字段权限
    └── 单次“保存授权” -> PUT /v1/roles/{id}/authorization
```
六态：`loading | empty | unconfigured | forbidden | error | success`；无角色、无页面、无组织树、无动作时分别 `unconfigured`。所有面向业务管理员的文案不得出现 ADR、`capability_code` 前缀说明、`/v1` 路径或英文枚举；技术码只允许出现在标记为“管理员技术明细”的可折叠区域和审计日志中。
| 操作 | 状态 | Capability | 契约 |
|---|---|---|---|
| `GET /v1/users`、`POST /v1/users`、`PATCH /v1/users/{id}` | 现有 | `iam.user.read/manage` | 用户列表/创建/启停；员工绑定独立动作 |
| `POST /v1/users/{id}/roles`、`DELETE .../{roleCode}` | 现有 | `iam.role.manage` | 角色分配/移除；禁止自我越权 |
| `GET /v1/users/{id}/permissions-preview` | 现有 | `iam.user.read` | 只读预览，展示页面/动作/字段/锚点 |
| `GET /v1/roles`、`POST /v1/roles`、`PATCH /v1/roles/{id}`、`DELETE /v1/roles/{id}` | 现有 | `iam.role.manage` | 内置角色不可改/删；复制单独端点 |
| `POST /v1/roles/{id}/copy` | 现有 | `iam.role.manage` | 复制动作能力；新角色页面授权留空；新 code 唯一 |
| `PUT /v1/roles/{id}/authorization` | 现有 | `iam.role.manage` + 字段/范围天花板 | `pages[]`、`capabilities[{capability,anchor_type,anchor_id,field_profile}]`、`reason`；一次事务；内置角色 409；未知页面 422；动作缺页面 422 |
| `GET /v1/roles/{id}/pages` | 现有 | `iam.role.manage` | 角色当前页面授权 |
| `GET /v1/pages/catalog` | 现有 | `iam.role.manage` | 代码拥有的页面目录；`read_only: true` |
| `GET/POST/PATCH/DELETE /v1/system/menus` | 现有 | `iam.menu.manage` | 仅菜单覆盖：`visible/sort_order/label`；不删除动作能力 |
| `GET /v1/capabilities` | 现有 | `iam.role.manage` | 只读能力目录，页面动作矩阵来源 |
| `PUT /v1/system/data-scopes/{id}`、`PUT /v1/system/field-policies/{field_key}` | 现有 | `iam.scope.manage`/`iam.field.manage` | 全局模板/字段上限；不冒充角色授权事实 |
### 2.3 状态机与语义
```text
角色：内置 CODE_OWNED（只读） -> 复制 NEW CUSTOM -> 编辑/删除
授权保存：草稿 -> 差异预览 -> 原子提交 -> 权限投影 auth_version++
页面目录：CODE -> 只读；菜单覆盖：DISPLAY_ONLY -> 可重置；字段只能收紧、锚点必须在能力允许集合内
```
内置角色复制语义（现有，保留）：动作能力从源角色逐项复制并按目标角色重新校验；页面授权为空；新角色 `is_template=false`，可改名/删除；内置角色本身 `PATCH/DELETE/PUT authorization` 返回 409 `TEMPLATE_ROLE_IMMUTABLE`。管理员不能授予超出自身上限的能力、字段档位或 SUPER_ADMIN；撤销当前会话后旧标签页再次提交必须 403。
- `/system/users` 进入 `iam.user.read`；创建/改状态 `iam.user.manage`；分配/移除角色 `iam.role.manage`；用户与员工允许非一对一。
- `/system/pages` 进入 `iam.permission.read`（或 `iam.menu.manage`）；目录只读；菜单覆盖写 `iam.menu.manage`。
- `/system/roles` 进入 `iam.role.manage`；动作授权保存 `iam.role.manage`；范围/字段只在角色授权载荷中生效，并受 `iam.scope.manage`/`iam.field.manage` 的全局上限约束。
- 字段：用户邮箱/手机 P2；角色 purpose P1；内部 code 只在管理员技术明细；审计差异不得输出密码、TOTP、会话令牌。

## 4. 权限负向测试
| 动作 | 未登录 | 无能力 | 跨范围 | 字段/范围 | 状态冲突 | 幂等/会话 |
|---|---|---|---|---|---|---|
| 用户列表/创建/改状态、分配角色 | 401 | 403 | 越界 404 | 联系方式 P2/不自升超管 | 重复账号或内置角色 409 | 同键 replay；auth_version++ |
| 页面目录读取、菜单覆盖写入、角色创建/复制/改名/删除 | 401 | 403 | 越界/非管理 404/403 | code 仅技术明细；purpose P1 | 未知页面 404；内置或 code 重复 409 | 同键 replay/只读 |
| 原子授权保存 | 401 | 403 | 未知页面 422 | 字段超限/锚点非法 422 | 内置 409 | 单事务、auth_version++ |
| 页面-only、撤销权限旧标签页、全局模板 | 401 | 403 | 越界 404 | 不能放宽 409 | 会话撤销 | 再次提交 403；隐藏不代替 403 |
