# FactoryHR V2.3 M17｜培训管理 — 详细实施计划
> **状态：Proposed — 待用户确认。** 本计划不得在规格批准前执行。**For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
**Goal:** 将 8 个培训子入口折叠进唯一 `/training` 工作区，课程、计划、场次、报名、签到、考试、反馈、档案使用真实关联与写入命令；培训报表归报表中心。
**Architecture:** `Talent/Training` 独占 `training_plans`、`training_courses`、`training_programs`、`training_sessions`、`training_enrollments`、`training_checkins`、`training_exams`、`training_feedback`。课程/计划/场次是配置与活动事实，报名与签到是参与事实，考试版本发表后冻结，反馈 append-only，档案和报表是实时聚合。前端只保留 `/training` 一个侧栏入口，场次详情为工作区内操作中心。
**Tech Stack:** Laravel 13 / PHP 8.3 / MySQL 8.4 / Vue 3.5 / TypeScript / Element Plus / PHPUnit / Vitest / Playwright / OpenAPI 3.1。
## Global Constraints
- 规范优先级：用户裁决 > 本计划 > V2.3 M17 模块规格 > V2.1 设计 > 历史文档；8 个 `FOLD` URL 不做重定向，registry、barrel、talent catalog、Vue 文件和旧测试一并删除。
- 一表一个写入模块；成绩、签到不得脱离报名与场次，档案/报表不得反写培训事实；写命令使用 `CommandRunner`/`IdempotencyRunner` + `Idempotency-Key` + `AuditRecorder`，唯一键兜底并发。
- 金额整数最小单位；学时由签到/签退推算；业务日期按公司时区与日历；未执行测试、E2E、迁移演练写 `NOT RUN`。

## 2. 目标契约
```text
/training
├── 筛选：计划/年度、课程、状态；工具栏：新建计划、新建课程、新建项目
├── Tabs：plans | courses | sessions | enrollments | checkins | exams | feedback | records | reports
└── 场次抽屉（?program=:id&session=:id）
    ├── 概览：时间、讲师、容量、地点、关联计划/课程
    ├── 报名：员工、状态、容量/候补；完成登记
    ├── 签到：到场/离场、补签原因、学时
    ├── 考核：场次考试、版本、发布、参与人
    └── 反馈：评分、问卷、匿名汇总
```
六态：`loading | empty | unconfigured | forbidden | error | success`；无场次时显示“新建场次”，不显示空表头；课程/计划缺失时 `unconfigured`。

### 2.3 状态机与唯一关联
```text
计划/课程/项目：ACTIVE -> ARCHIVED（被场次引用只归档；存在未结束场次时 409）
场次：SCHEDULED -> COMPLETED / CANCELLED（有有效报名时 409）
报名：ENROLLED -> ATTENDED -> COMPLETED；ENROLLED/ATTENDED -> CANCELLED
考试：DRAFT -> PUBLISHED（终态，追加新版本）；反馈：RECORDED（append-only）
```
关联：`training_sessions.program_id` 必填，`plan_id/course_id` 可空且必须一致；`training_enrollments.session_id+employment_id` 唯一；`training_checkins.session_id+employment_id` 唯一；`training_feedback.enrollment_id` 必填并从报名派生 session/employment；`training_exams.session_id` 可空，非空时必须与 `course_id` 同属该场次。
页面进入 `training.program.read`；计划/课程/项目/场次/报名/签到/完成/考试/反馈/档案/报表分别使用上表 capability。员工本人只能读自己的报名、签到、档案与反馈；主管只能读下属；`training.record.read` 导出需字段白名单。课程成本为整数分；反馈评分为受限字段；匿名反馈不得带出评价人身份。
