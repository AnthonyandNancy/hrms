# FactoryHR V2.3 M02｜首页仪表盘 — 详细实施计划

> **状态：** Proposed — 待用户确认；本计划不得在规格批准前执行。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将六个旧看板入口删除并合并到唯一 `/dashboard`，让指标、单位、口径、不可用原因与下钻全部由服务端业务语义驱动，界面不出现英文调试信息。

**Architecture:** Reporting 拥有指标查询与投影；Dashboard 只读 `GET /v1/reporting/dashboard` 与 `GET /v1/reporting/dashboard/metrics/{metric}`；每个指标由同一 `MetricQueryBuilder` 计算总量与明细，禁止前端二次计算。

**Tech Stack:** Laravel 13 / PHP 8.3 / Vue 3.5 / ECharts 5 / PHPUnit / Vitest / Playwright。

## Global Constraints

- 旧 `/dashboard/departments`、`/workforce`、`/changes`、`/tasks`、`/recruitment` 必须删除，不保留重定向。
- 指标必须同时返回 `code/value/unit/status/reason/asOf/scope`；不可用不得显示为 0。
- `MINOR_UNITS` 必须换算为“元”；`COUNT` 按语义显示“人/份/项”，不能统一“COUNT”。
- 所有指标查询必须经 `Authorizer::constrain()`；下钻与卡片同口径。
- 不执行测试写 `NOT RUN`。

### 0.3 当前缺陷

1. `MetricQueryBuilder::METRICS` 的 label 为 `Headcount`、`Probation` 等英文，predicate 为英文调试句。
2. `DashboardService::dashboard()` 返回 `greeting: 'Welcome back'`、`drilldownLabel: 'View details'`。
3. `frontend/src/modules/reporting/api.ts` 的 `metricUnitText()` 对 `MINOR_UNITS` 返回“最小货币单位”，不是金额。
4. `payroll_cost_by_entity`、`recruitment_funnel` 在 METRICS 中固定标记不可用，但 V2.3 要求报表/招聘模块闭环后应可用；计划必须随 M13/M16 解锁。
5. 旧五个看板页经 `PlatformWorkspace` 渲染，截图中的 `Probation/COUNT/as-of` 直接泄露。

## 1. 目标契约

### 1.1 DTO

```json
{
  "asOf": "2026-11-27",
  "freshness": "2026-11-27T05:00:00Z",
  "metrics": [
    {
      "code": "headcount",
      "label": "在职人数",
      "value": 42,
      "unit": "PERSON",
      "status": "AVAILABLE",
      "reason": null,
      "scope": "COMPANY",
      "period": "AS_OF",
      "drilldown": { "route": "/hr/employees", "query": { "as_of": "2026-11-27" } }
    }
  ]
}
```

### 1.2 单位映射

| 指标 | unit | 中文 |
|---|---|---|
| headcount / probation | `PERSON` | 人 |
| pending_approvals | `ITEM` | 项 |
| contract_expiring | `CONTRACT` | 份 |
| leave_liability | `MINUTE` | 分钟 |
| payroll_cost | `CNY_CENT` | 元（后端整数分，前端格式化） |
| recruitment_funnel | `PERSON` | 人 |

### 1.3 六态

- loading：骨架；
- empty：`metrics.length === 0` 且无错误；
- unconfigured：指标未配置（`status === 'UNCONFIGURED'`）；
- forbidden：403；
- error：请求失败；
- success：至少一个 AVAILABLE 指标。

- [ ] **Step 3: 实现格式化**

```ts
export function formatMetric(metric: Pick<MetricCardMetric, 'code' | 'unit' | 'value' | 'status'>): { value: string; unit: string } {
  if (metric.status !== 'AVAILABLE') return { value: '—', unit: '' }
  if (metric.unit === 'CNY_CENT') return { value: formatMoney(metric.value, { withSymbol: false }), unit: '元' }
  const units: Record<string, string> = { PERSON: '人', ITEM: '项', CONTRACT: '份', MINUTE: '分钟' }
  return { value: new Intl.NumberFormat('zh-CN').format(metric.value), unit: units[metric.unit] ?? '' }
}
```
