# FactoryHR V2.4 T18｜MCP 验收证据模板

> 每个证据项复制本模板，保存为
> `docs/implementation/v24/18-mcp-acceptance/evidence/MCP-<模块>/P<入口三位>/<证据ID>-<NNN>-<动作短名>-<UTC时间>.md`（如 `evidence/MCP-M13/P089/`）。
> 截图、snapshot、网络记录放同编号子目录，文件名使用同一 UTC 时间戳。
